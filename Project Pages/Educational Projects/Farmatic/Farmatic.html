About

A small project to explore 2D game development in Godot, becomes Farmatic.
Hoe, Plant, Harvest, and Sell crops to become the richest in all the lands.
I mean, you're the only farmer well and person in the land, but hey, you can still be the richest.

Project Backstory

I started this project as a way to learn Godot, and to explore 2D game development. I used a Zenva course to create and learn from this game. I intend to add more features to Farmatic, however at the moment, I have more Zenva course I want to complete first. We will see what the futures holds for this game.

Controls

  • WASD - Move
  • F - Hoe, Water, Plant, Harvest, depending the tool you have equipped
  • LMB - Click on UI Elements
